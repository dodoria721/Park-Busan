1. 설계 개요 (Design Overview)
1.1 목적 및 범위
부산 지역 공영주차장을 대상으로 자연어 조건 분석, 목적지 검색, 반경 2km 이내 주차장 조회, 예상 주차 요금 계산, 실시간 주차 가능 정보 조회, 맞춤형 추천 및 지도 표시 기능을 제공하는 모바일 애플리케이션을 설계한다.
사용자는 로그인 없이 자연어로 주차장을 검색하고, 이전 검색 조건을 유지하면서 후속 질의를 수행할 수 있다. 검색된 주차장의 위치 및 상세 정보를 확인하고 외부 지도 서비스의 길찾기 기능을 이용할 수 있다.
관리자 전용 기능, 주차 요금 안내판 이미지 분석, 주차장 예약 및 결제 기능은 개발 범위에서 제외한다.
1.2 관련 문서
본 설계서는 파크부산(ParkBusan) 요구사항 명세서(SRS)를 기반으로 작성하였다.
SRS에서 정의한 기능 요구사항 FR-001~FR-019, 비기능 요구사항 NFR-001~NFR-008 및 AI 관련 요구사항을 설계 기준으로 사용한다.
추천 기능은 SRS의 FR-012에 따라 확인된 만차 주차장 및 예산 초과 주차장을 제외하고 직선거리 기준으로 정렬한다. AI는 자연어 조건 분석과 선택적인 추천 이유 생성에 활용한다.
세부 구현 기술과 외부 API의 실제 제공 범위는 개발 초기 검증을 거쳐 확정한다.

2. 시스템 아키텍처 (System Architecture)
2.1 전체 아키텍처
설치형 앱 클라이언트는 React Native·Expo로 제안하고, API 서버는 Next.js Route Handler를 사용한다. 앱과 서버는 별도로 빌드·실행하며 HTTPS JSON으로 통신한다. 서버에서 조건 검증·요금 계산·추천·DB·외부 API 호출을 수행한다. Vercel은 서버 배포에 사용하고 앱 설치 파일은 Android APK로 제공한다. 앱 UI를 Next.js로 구현하지 않는다
